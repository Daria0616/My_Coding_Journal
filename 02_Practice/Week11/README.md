- [P5724 求极差](P5724_求极差.cpp)：求最小值时条件误写成 `arr[i] < Max`（应为 `< Min`），且 `Min` 未赋初值；最大值、最小值应在同一趟遍历中维护，初值都取 `arr[0]`。
- [P5735 距离函数](P5735_三角形周长距离函数.cpp)：距离函数形参顺序写成 `(x1, x2, y1, y2)`，而调用按 `(x1, y1, x2, y2)` 传参，横纵坐标错位；形参顺序需与调用处一致。
