# Excel 卡点

## 25 年真题

- 使用 `AND(, )`、`OR(, )`，而不是 `&&` 和 `||`。

## 24 年真题

- IF 嵌套函数中，**中英文符号**容易混乱。
- 对数据应用条件格式时，忘记**选择数值型**（系统默认为百分比）。

## 22 年真题

- 漏掉**绝对引用**（`VLOOKUP`、`RANK`、`IF`、`AVERAGEIF`），导致 `RANK` 排名不对。
- `VLOOKUP` 函数运用不熟练，对题目理解有歧义。
- 把握不了引用其他表格的技巧。

## 21 年真题

- `AVERAGEIF` 函数应用不熟悉。

1. **合并与对齐** —— 合并后居中 ≠ 跨列居中，以及怎么点一下就看出来；合并之后按列引用会报 `#VALUE!`。
2. **隐藏与计算** —— 隐藏行列照算（SUM/RANK/ 图表），只有 SUBTOTAL (109)/AGGREGATE 会跳；而复制时正好相反，隐藏行**不**被复制。
3. **安全与存储器** —— 防病毒四环（含 “定期备份” 这条最容易漏的）；RAM/ROM/ 外存 / Cache 的属性与速度层次。
A 对（RAM 靠电容存电荷，易失）；**B 对**（ROM 出厂写入、正常只读、断电保留，Flash/EPROM 可改写但 “断电保留” 不变）；C 对（硬盘、U 盘、光盘是外存）；D 错（Cache 速度**比内存快**）。
拓展：存储层次 寄存器 > Cache > 内存 > 外存，越往后越慢、越大、越便宜。L1/L2/L3 用 SRAM 把热数据搬到 CPU 旁边，靠局部性原理压平均访问时间。问 “断电丢失”→ RAM 和 Cache；问 “属于外存”→ 硬盘、U 盘、光盘、磁带。
4. **函数参数顺序** —— SUMIF 与 SUMIFS 正好相反的口诀；RANK 三参数与并列跳号；VLOOKUP 第 3 参数从 “区域第一列” 起算；逆向查找四法。
5. **条件格式的判据** —— 百分比格式把 5% 存成 0.05 导致 “大于 5000” 整列命中；`$D$5` 这种固定格引用在排序后会错位；图案填充落在 x14 扩展、通用解析器读不到；同区多条数据条规则叠加的隐患。
6. **数据透视表与分类汇总** —— 值区默认汇总按字段类型分（数值求和、文本计数）；分类汇总 11 种方式；嵌套与替换互斥。
7. **页面设置的两个互斥项** —— “缩放 98%” 和 “调整为 1 页宽 1 页高” 不能并存，看到比例框还是 98% 就说明没勾。

1. **IP 分类表** —— 五类地址的第一段范围、首位特征、默认掩码，加私有段（10 / 172.16 / 192.168）、特殊地址（127.0.0.1、169.254、0.0.0.0）、以及 `198.168`、`172.16` 这两个 “看着像但不是” 的陷阱。
2. **冯・诺依曼 vs 图灵** —— 存储程序体系、五大部件；图灵是图灵机与图灵测试，摩尔是摩尔定律。
3. **数据系列增删** —— 设计→选择数据里增删，删系列不删数据，图表与数据源联动；绝对化表述基本是错项。
4. **顶端标题行** —— `$1:$1`、每页重复、按工作表保存、与页眉的区别、常和 1 页宽高组合考。
5. **错误值成组辨析** —— 五组对应的表格，加一句最好用的判据：“找不到是 `#N/A`，被删了是 `#REF!`”，这两个最容易被选项互换；再补 `IFERROR` 兜底写法。
