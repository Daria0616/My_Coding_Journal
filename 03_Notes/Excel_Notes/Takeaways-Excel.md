# Excel 要点

## 一、界面与文件规则

- 文件名不能包含 `\ / : * ? " < > |` 这九个半角符号；汉字、字母、`%` 都可以。
- 功能区选项卡：文件、开始、插入、页面布局、公式、数据、审阅、视图；"切换"不是选项卡。
- 拖动功能区空白处可移动窗口。
- "插入—公式"不是 Excel 的命令，插入选项卡里没有公式命令；可在单元格直接输入函数、在编辑栏输入，或用 `fx` 按钮插入。
- 工作表是 Excel 的基本操作对象，任何数据处理都需要在工作表中完成。

## 二、快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Alt` | 吸附单元格边界 |
| `F4` | 绝对引用 |
| `Ctrl + O` | 打开已有工作簿 |
| `Ctrl + P` | 打印 |
| `Ctrl + N` | 新建工作簿 |
| `Ctrl + S` | 保存 |
| `Ctrl + Enter` | 把相同内容 / 公式一次性填入选中区域的全部单元格（不移动光标） |
| `Ctrl + D` | 向下填充相同内容 |
| `Ctrl + R` | 向右填充 |
| `Ctrl + E` | 快速填充（按已有规律自动拆分、合并并填充） |
| `Ctrl + ;` | 插入当前日期（固定值，不随日期刷新） |
| `Ctrl + Shift + ;` | 插入当前时间（固定值） |
| `Ctrl + Home` | 回到 A1 |
| `Ctrl + End` | 跳到有效数据区右下角 |
| `Ctrl + Shift + End` | 从当前格选到数据区域右下角 |
| `Ctrl + Shift + L` | 添加 / 取消筛选按钮 |
| `Ctrl + Shift + →` | 把选区扩展到本行数据末尾（不等于选中整行） |

| `Enter` | 确认公式并显示结果 |

| `Ctrl + Shift + Enter` | 数组公式的旧式确认 |

> 日期 / 时间要随刷新，用 `TODAY()` / `NOW()`，而不是上面的固定插入。

## 三、数据输入规则

- 18 位身份证号必须按文本输入：数值型只能精确表示 15 位有效数字。
- 输入分数：先输 `0` 和一个空格，再输 `1/2`（即 `0 1/2`）；直接输入会被当成日期。
- 日期用 `/` 或 `-` 分隔年、月、日。
- 加单引号会把内容变成文本；方括号在公式中没有数学含义。
- 负数：数字前直接写负号，也可用圆括号把负数括起来。
- 选中多个（可不连续）单元格，输入内容后按 `Ctrl + Enter`，一次性填入相同数据。
- 对单个数字按住 `Ctrl` 拖动填充柄，得到步长为 1 的递增序列。
- 支持导入网页中的表格数据、文本与数据库数据，导入后即可统计分析。

## 四、格式与显示

- 小数位数设为 0 时会四舍五入：`3.05` 显示为 `3`；单元格里存的仍是 `3.05`，参与计算用原值。
- 行高可单行或多行同时调整，拖动行号交界即可；行高变大不会改变字号。
- "开始—段落"是 Word 的说法，Excel 没有该组。
- 双击列标右边界，可按内容自动调整列宽，让字符完整显示。
- 自动换行：在"开始"选项卡"对齐方式"组，或在"设置单元格格式"的"对齐"选项卡勾选；不在"数字"选项卡，也不在"页面布局"中。
- 数字格式分类：常规、数值、货币、会计专用、日期、时间、百分比、分数、科学记数、文本、特殊；没有"绝对值"这一类。
- 单元格里能放文字、数值、公式、批注、边框、底纹、超链接；图形是浮在单元格上方的独立对象，不属于单元格内容。
- 套用表格格式要求数据区域规整，含合并单元格时无法套用。

## 五、公式基础与运算符

- 公式以 `=` 开头；常量是公式的常用要素；函数由函数名与参数组成；函数名不区分大小写。
- 运算符：算术（`+ - * / ^ %`）、文本（`&`）、比较（`= > <`）、引用；也包括逻辑函数产生的逻辑运算。
- 比较运算符的结果只有两个逻辑值 `TRUE` 与 `FALSE`，不是 1 与 0（参与运算时会转换）。
- 优先级从高到低：引用运算符 → 算术运算符 → 文本运算符 → 比较运算符；负号与百分号属算术最高级；`%` 仅低于负号，高于连接符 `&` 与比较运算符。
- 区域不能直接相加 / 相除：`=(B1:B3)/3` 这种写法非法；应写 `=AVERAGE(A1+A2+A3+A4)`。

## 六、常用函数

- `MID(文本, 起始位置, 长度)`，如 `MID(A1,7,8)`；`MID(A1,6,8)` 起点错一位；`LEFT` / `RIGHT` 取不到中间段。
- `NOW()` 返回当前日期和时间（含时分秒）；只要日期用 `TODAY()`；显示函数本身说明公式未按等号输入。
- 平均值且忽略 0：`=AVERAGEIF(A2:A10,"<>0")`；或 `=SUM(A2:A10)/COUNTIF(A2:A10,"<>0")`，分母随非零个数动态变化，不能写死为 9。
- `COUNT` 只统计数值型单元格；`TOTAL` 不是 Excel 函数。
- `VLOOKUP` 返回 `#N/A`：查找值在首列找不到，或查找值与首列类型不一致（数字对文本）；区域未绝对引用只导致填充错位，首列未升序只影响近似匹配的准确性。

## 七、错误值对照

| 错误值 | 含义 |
| --- | --- |
| `#REF!` | 引用的单元格已被删除 / 区域无效 |
| `#VALUE!` | 数据类型不匹配（如文本参与算术运算）；参数个数不对 |
| `#NUM!` | 数值参数无效（如负数开平方、参数超出定义域）；无可用数值 |
| `####` | 列宽不足 |
| `#DIV/0!` | 除数为 0 |
| `#N/A` | `VLOOKUP` 查不到查找值 |

## 八、区域、引用与命名

- 矩形区域用对角线两端表示，即左上角 `C3` 与右下角 `N11`；两段写法之间用空格，表示两个区域的交集，不是并集。
- 跨表引用格式：`工作表名!单元格地址`，感叹号是分隔符；工作表名含空格或特殊符号时再加一对单引号，如 `'一季度 汇总'!B6`。
- 为区域命名：选中区域，在名称框直接输入名称并回车，一步完成；供公式和跨表引用使用。
- 公式审核："追踪引用单元格 / 追踪从属单元格"用箭头画出依赖关系；审阅组管拼写检查和批注，与公式无关。

## 九、工作表管理

- 同一工作簿内工作表名必须唯一，重名时 Excel 会提示改名或自动加后缀。
- 工作表名可以汉字开头，最多 31 个字符（不是 32，且不限字母开头）；重命名后还可再改，复制出的工作表会自动加数字后缀；不能定义成任意字符、任意长度。
- 默认以 `Sheet1`、`Sheet2`… 命名；可为工作表标签设置颜色；标签高度不能更改，也不能"同时显示相同的工作表"。
- Excel 2010 新建工作簿默认创建 3 张工作表（Sheet1—Sheet3）；2016 及以后默认 1 张。
- 工作表可隐藏、可移动或复制到其他工作簿、可插入与删除；也可设置保护。
- 拖动标签同时按 `Ctrl` 才复制（按 `Shift` 是移动）；可用"移动或复制—建立副本"做备份；可用鼠标拖动改变前后位置。
- `Ctrl+C` / `Ctrl+V` 只能复制单元格，不能复制整张工作表。
- 把多张工作表成组后右键删除，可一次删除多张。
- 标签变黑底白字是进入了重命名编辑态，直接敲新名字回车即可；改名不影响表内数据与公式引用。
- 删除工作表不进回收站、也不能 `Ctrl+Z` 撤销，属于不可撤销操作，表内数据随之消失（删表前要备份）。
- 保护工作簿可分别保护"结构"和"窗口"，不是只能选其一；保护结构后不能插入、删除、移动、重命名工作表，但可以新建工作簿；锁定结构与窗口可防止他人增删工作表或改变窗口布局。

## 十、单元格与行列编辑

- 单击行号可选整行；在行号上拖动可选连续多行；按 `Ctrl` 单击行号可选不相邻多行。
- `Delete`（`Del`）键：只清除选中单元格的内容，保留格式与批注，单元格本身仍在。
- "清除"命令可清除格式、批注、内容（也可清除全部），但不会删除单元格本身；清除＝擦掉内容或格式，格子还在原处；删除＝连格子一起抽走，右侧或下方单元格补位。
- 插入单元格只是让右侧或下方已有单元格整体挪位，行列总数不变；要增加整行整列得用"插入行 / 插入列"。
- 插入几行就先选几行，插入位置落在选中区域的上一行。
- 用鼠标拖放复制单元格数据要按住 `Ctrl` 键（`Shift` 是强制移动）。
- 复制后右键—选择性粘贴—格式（或"仅粘贴格式"），只搬格式不动值；直接复制会把内容和格式一起带过去。
- 行列互换最快是复制整表后用"选择性粘贴—转置"。

## 十一、筛选、排序、分类汇总与透视表

- 筛选的作用：从数据列表中查找符合条件或排除不符合条件的记录；分类汇总做统计，排序只重排顺序，透视表做交叉汇总。
- 数据清单（列表）就是简易数据库：可直接改单元格、插入行、删除行，也可用记录单增删改，还支持排序、筛选、分类汇总。
- 添加筛选按钮：选中标题行任意单元格，按 `Ctrl + Shift + L`；或在"数据"选项卡"排序和筛选"组单击"筛选"（"开始"选项卡的"排序和筛选"组也有同样命令）。筛选后可直接对结果编辑、设格式、做图表与打印，但操作只作用于可见行。
- 高级筛选：条件区域中，同一行的多个条件表示"与"（必须同时满足），不同行的条件表示"或"（满足任一即可）。
- 分类汇总前必须按分类字段排序，把同类记录排在一起，否则汇总结果会被拆成多段；关键字段只能有一个、汇总后可删除；汇总方式包括计数、平均值、最大值等，不只求和。
- 数据透视表入口："插入"选项卡"表格"组中的"数据透视表"，或按 `Alt+D+P`（依次按下）打开向导；按钮位于"插入—表格"功能组。
- 透视表要求区域连续（不能有空行空列），且必须包含列标题（字段名）；不要求全部为数值型；允许存在空白单元格（只是该字段会出现"空白"项）。
- 切片器按字段单独建：透视表里每个可作为筛选的字段都能生成一个独立按钮面板，点选即筛选；多个切片器还能联动。
- 透视表的关键字段不能用来自定义重命名。

## 十二、图表

- 图表与数据源联动：源数据改变，图表自动更新；删除源数据，图表随之变化或变空。工作簿保存时，工作表与图表作为同一个文件保存，不会被拆成两个文件。
- 图表所在的工作表也可以打印，工作表中还可以插入超链接。
- 图表构成包括绘图区、图例、图表区、坐标轴；可包含图例、图表标题、数据标签等元素；公式计算属于单元格的计算方式，不是图表组成元素。
- 图表类型选择：折线图展示相等时间间隔下数据的连续性与变化趋势；饼图看占比；柱形图做比较；面积图看累积。
- 迷你图只有折线、柱形、盈亏三种类型；曲面图是独立的图表类型，不是迷你图。
- 在"图表元素"中勾选"数据表"，可在图表下方显示参与绘图的源数据（即模拟运算表）。
