# Excel 要点

| 快捷键 | 作用 |
| --- | --- |
| `Alt` | 吸附单元格边界 |
| `F4` | 绝对引用 |
1. 文件名不能包含 \ / : * ? " < > | 这九个半角符号
2. 打开已有工作簿用 Ctrl + O
3. 功能区：（选项卡）文件、开始、插入、页面布局、公式、数据、审阅、视图等选项卡（无切换）；拖动功能区空白处可移动窗口
4. 18 位身份证号必须按文本输入：数值型只能精确表示 15 位有效数字
5. 要输入分数，必须先输入 0 和一个空格，再输入 1/2（即 0 1/2）（直接输入会被当成日期）
6. 日期用 / 或 - 分隔年、月、日
7. 选中区域后输入内容，按 Ctrl + Enter 可把相同内容一次性填入选中区域的全部单元格。
8.“切换”不是选项卡,选项卡有文件、开始、插入、页面布局、公式、数据、审阅、视图.
9.文件名不能包含 \ / : * ? " < > | 这九个半角符号,汉字、字母、% 都可以
10.打开已有工作簿用 Ctrl + O；Ctrl + P 打印、Ctrl + N 新建、Ctrl + S 保存
11.高级筛选中同一行的多个条件是“与”，不同行的条件是“或”
创建透视表要求区域连续且含列标题；允许空白单元格存在，也不要求全部为数值型
切片器正是按字段单独建的：数据透视表里每个可作为筛选的字段都能生成一个独立按钮面板，点选即筛选，多个切片器还能联动。
Ctrl+; 插入当前日期，Ctrl+Shift+; 插入当前时间；两者插入的都是固定值，不会随日期刷新（要刷新用 TODAY()/NOW()）
数据有效性（新版叫“数据验证”）在“数据”选项卡；设置“允许：小数/整数”并配上出错警告，输错就弹提示。
单元格里能放文字、数值、公式、批注、边框、底纹、超链接；图形是浮在单元格上方的独立对象，不属于单元格内容。
数值格式的小数位数设为 0 时会四舍五入，3.05 显示为 3；单元格里存的仍是 3.05，参与计算用原值。在Excel中，单元格A1的数值格式设为整数，当输入"3.05"时，屏幕显示为3__
行高可按行调整也可多行同时调整，用鼠标拖动行号交界即可；行高变大不会改变字号；“开始—段落”是 Word 的说法，Excel 没有该组。
双击列标右边界可按内容自动调整列宽，目的正是让字符完整显示
xcel 公式可用算术运算符（+ - * / ^ %）、文本运算符（&）、比较运算符（= > <）、引用运算符，也包括逻辑函数产生的逻辑运算
删除 A3 后公式引用的单元格已不存在，形成无效引用，显示 #REF!；#VALUE! 表示数据类型不匹配（如文本参与算术运算）；引用无效是 #REF!，无可用数值是 #NUM!，列宽不足显示 ####
#NUM! 表示函数或公式中的数值参数无效（如对负数开平方、参数超出定义域）；函数照样会报错：区域被删得 #REF!、除数为 0 得 #DIV/0!、VLOOKUP 查不到得 #N/A、参数个数不对得 #VALUE!
公式输入完成后按 Enter 确认并显示结果；Ctrl+Enter 用于把公式填入选中区域，Shift+Enter 上移，Ctrl+Shift+Enter 是数组公式的旧式确认。
比较运算符的结果只有两个逻辑值 TRUE 与 FALSE，不是 1 与 0（虽然参与运算时会转换）
百分号 % 属于算术运算符的最高一级（仅次于负号），高于连接符 & 与比较运算符
公式审核组里的“追踪引用单元格/追踪从属单元格”用箭头画出谁依赖谁；审阅组管的是拼写检查和批注，与公式无关
自动换行在“开始”选项卡“对齐方式”组，或在“设置单元格格式”的“对齐”选项卡勾选；它不在“数字”选项卡，也不在“页面布局”中。
为区域命名最快的操作是：选中区域，在名称框中直接输入名称并回车，一步完成,单元格能命名（选中后在名称框输入名字回车），供公式和跨表引用使用
优先级从高到低为引用运算符 → 算术运算符 → 文本运算符 → 比较运算符，负号与百分号属算术的最高级。
负数参与四则运算时要保证负号明确，可在数字前写负号，也可用圆括号把负数括起来；加单引号会把内容变成文本，方括号在公式中没有数学含义。
不相邻用 Ctrl，Shift 是连续扩展区域
形区域用对角线两端表示，即左上角 C3 与右下角 N11；写两段再用空格，表示的是两个区域的[交集]，不是并集。
Ctrl+Home 回到 A1；Ctrl+End 才是跳到有效数据区的右下角，这两个键常被配对考。
跨表引用格式固定为“工作表名!单元格地址”，感叹号是分隔符；工作表名含空格或特殊符号时还要再加一对[单引号]，写成 '一季度 汇总'!B6
“插入—公式”不是 Excel 的命令，插入选项卡里没有公式命令。可在单元格直接输入函数、在编辑栏输入、用 fx 按钮插入
“A2:A10 的平均值且忽略 0”有两种写法：=AVERAGEIF(A2:A10,"<>0")，或用 =SUM(A2:A10)/COUNTIF(A2:A10,"<>0") 先求和再数非零个数——后者分母是动态的，不能写死为 9。分母随非零个数变化
数字格式分类含常规、数值、货币、会计专用、日期、时间、百分比、分数、科学记数、文本、特殊；没有“绝对值”这一类。
COUNT 只统计数值型单元格，TOTAL 不是 Excel 函数
公式要以 = 开头、常量是公式的常用要素、函数由函数名与参数组成，这三条都对；函数名不区分大小写
用 MID(文本, 起始位置, 长度) 即 MID(A1,7,8)；MID(A1,6,8) 起点错一位，LEFT/RIGHT 取不到中间段
NOW() 返回当前日期和时间（含时分秒）；只要日期用 TODAY()，显示函数本身说明公式未按等号输入
=(B1:B3)/3 这种区域直接相除的写法非法，=AVERAGE(A1+A2+A3+A4)（区域不能直接相加）
VLOOKUP 返回 #N/A 主要因查找值在首列找不到，或查找值与首列类型不一致（数字对文本）；区域未绝对引用只导致填充错位，首列未升序只影响近似匹配的准确性。
“开始—填充”命令里可选：向下、向右、向上、向左、系列、成组工作表、快速填充。序列类型包括等差序列、等比序列、日期、自动填充（星期、月份、甲乙丙丁等内置序列）。**“排序”**不是填充序列类型。排序是数据分析功能，不是序列类型。
先选中多个（可不连续）单元格，输入内容后按 Ctrl + Enter，可一次性填入相同数据，Ctrl + E 快速填充可依据已输入内容的规律自动拆分、合并并填充
对单个数字按住 Ctrl 拖动填充柄，得到的是步长为 1 的递增序列
向下填充相同内容用 Ctrl + D；Ctrl + R 向右填充，Ctrl + E 快速填充，Ctrl + Enter 填入选区
