## 第 1 题

若有下述语句：`int x=10; x-=x+x;` 运行结果是（ ）。

- A、-20
- B、-10
- C、0
- D、10

**【参考答案】B（-10）**

**解析：** `x-=x+x` 等价于 `x = x - (x+x) = 10 - 20 = -10`。复合赋值右侧整体先算。

## 第 2 题

有以下程序：

```cpp
#include <iostream>
using namespace std;
int main()
{
    int a = 1, b = 0;
    b = a + b;
    cout << b << " ";
    a = 2 * b;
    cout << a << endl;
}
```

- A、0 0
- B、1 0
- C、3 2
- D、1 2

**【参考答案】D（1 2）**

**解析：** `b=a+b=1`，先输出 1；`a=2*b=2`，再输出 2，结果为 `1 2`。

## 第 3 题

输入并运行以下程序（ch1='a'，ch2='b'，ch3='c'），程序运行结果是（ ）。

```cpp
#include <iostream>
using namespace std;
void main()
{
    char ch1, ch2, ch3;
    cin >> ch1 >> ch2 >> ch3;
    cout << "ch1=" << (int)ch1 << "," << "ch2=" << (int)ch2 << "," << "ch3=" << ch3 << endl;
}
```

- A、ch1=a,ch2=b,ch3=c
- B、ch1=97,ch2=98,ch3=c
- C、ch1=97,ch2=98,ch3=99
- D、ch1=a,ch2=b,ch3=99

**【参考答案】B（ch1=97,ch2=98,ch3=c）**

**解析：** ch1、ch2 强制转换为 int，输出 ASCII 码 97、98；ch3 未转换，按字符原样输出 'c'。

## 第 4 题

输入并运行以下程序，程序运行结果是（ ）。

```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int main()
{
    cout << 10 << " " << -20 << endl;
    cout << setiosflags(ios::showpos) << 10 << " " << -20 << endl;
}
```

- A、+10 -20　+10 -20
- B、10 -20　10 -20
- C、10 20　+10 -20
- D、10 -20　+10 -20

**【参考答案】D（10 -20　+10 -20）**

**解析：** 默认正数前不显示正号，第一行输出 `10 -20`；设置 `showpos` 后正数前强制加 `+`，第二行输出 `+10 -20`。

## 第 5 题

输入并运行以下程序，程序运行结果是（ ）。

```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int main()
{
    cout << 10.0 / 5 << endl;
    cout << setiosflags(ios::showpoint) << 10.0 / 5 << endl;
}
```

- A、2.00000　2.00000
- B、2　2
- C、2　2.00000
- D、2.00000　2

**【参考答案】C（2　2.00000）**

**解析：** `10.0/5=2.0`，默认输出 `2`；设置 `showpoint` 后强制显示小数点及尾随零，输出 `2.00000`。
