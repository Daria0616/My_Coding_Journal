## 第 1 题

设 x、t 均为 int 型变量，若有 `x=10`，执行语句 `t=x && x>10;` 后，t 的值是（ ）。

- A、10
- B、1
- C、0
- D、-1

**【参考答案】C（0）**

**解析：** `x=10` 非零为真，`x>10` 为假；真 && 假 = 0，故 t=0。

## 第 2 题

设 x、y、t 均为 int 型变量，执行 `x=2; y=0; t=x || (y=y+1);` 后，t 和 y 的值分别是（ ）。

- A、t=2,y=0
- B、t=1,y=0
- C、t=0,y=1
- D、t=2,y=1

**【参考答案】B（t=1,y=0）**

**解析：** `||` 左侧 x=2 非零为真，右侧短路，`y=y+1` 不执行，y 保持 0；逻辑结果为真，t=1。

## 第 3 题

运行下面的程序，如果输入 2，输出结果是（ ）。

```cpp
int main()
{
    int x;
    cin >> x;
    if (x++ > 5) cout << x;
    else cout << x--;
}
```

- A、0
- B、1
- C、2
- D、3

**【参考答案】D（3）**

**解析：** `x++` 后置，先用 2 比较 `2>5` 为假，x 变为 3；走 else 分支 `x--`，先用 3 输出，x 再变 2，故输出 3。

## 第 4 题

以下选项中，与 `if(a==1) a=b; else a++;` 功能不同的 switch 语句是（ ）。

- A、`switch(a){ case 1:a=b; break; default:a++; }`
- B、`switch(a==1){ case 0:a=b; break; case 1:a++; }`
- C、`switch(a){ default:a++; break; case 1:a=b; }`
- D、`switch(a==1){ case 1:a=b; break; case 0:a++; }`

**【参考答案】B**

**解析：** 原逻辑：a==1 成立时 a=b，否则 a++。B 中 `a==1` 成立结果为 1，却对应 `a++`；不成立结果为 0，却对应 `a=b`，两个分支正好相反，功能不同。

## 第 5 题

有以下程序，程序运行后输出结果是（ ）。

```cpp
#include <iostream>
using namespace std;
int main()
{
    int a = 1, b = 2, c = 3, d = 0;
    if (a == 1 && b++ == 2)
        if (b != 2 || c-- != 3)
            cout << a << ',' << b << ',' << c;
        else cout << a << ',' << b << ',' << c;
    else cout << a << ',' << b << ',' << c;
    return 0;
}
```

- A、1,2,3
- B、1,3,2
- C、1,3,3
- D、3,2,1

**【参考答案】C（1,3,3）**

**解析：** `a==1` 为真；`b++==2` 先用 2 比较为真，b 变为 3。内层 `b!=2` 为真，`||` 短路，`c--` 不执行，c 仍为 3。输出 1,3,3。

## 第 6 题

输入并运行以下程序，程序运行结果是（ ）。

```cpp
#include <iostream>
using namespace std;
int main()
{
    int a = 3, b = 5, c = 6;
    switch (a)
    {
        case 1:
        case 2:
        case 3: cout << b << "+" << c << "=" << b + c << endl;
        case 4: cout << b << "-" << c << "=" << b - c << endl;
        case 5: cout << b << "*" << c << "=" << b * c << endl; break;
        case 6: cout << b << "/" << c << "=" << b / c << endl; break;
        default: cout << "a的值不正确！" << endl;
    }
}
```

- A、5+6=11
- B、5+6=11　5-6=-1　5*6=30
- C、5+6=11　5-6=-1
- D、5+6=11　5-6=-1　5*6=30　5/6=0.8333

**【参考答案】B**

**解析：** a=3 从 case 3 进入，case 3、4 后均无 break，向下穿透到 case 5：依次输出 5+6=11、5-6=-1、5*6=30，case 5 后 break 结束。
