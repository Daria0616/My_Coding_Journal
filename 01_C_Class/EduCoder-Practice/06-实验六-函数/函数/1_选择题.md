## 第 1 题

有以下程序，程序运行后的输出结果是（ ）。

```cpp
#include <iostream>
using namespace std;
int f(int x, int y) { return ((y - x) * x); }
int main()
{
    int a = 4, b = 5, c = 6, d;
    d = f(f(a, b), f(a, c));
    cout << d << endl;
}
```

- A、15
- B、16
- C、17
- D、18

**【参考答案】B（16）**

**解析：** f(a,b)=f(4,5)=(5-4)*4=4；f(a,c)=f(4,6)=(6-4)*4=8；d=f(4,8)=(8-4)*4=16。

## 第 2 题

以下程序运行后，输出结果是（ ）。

```cpp
#include <iostream>
using namespace std;
int f(int n);
int main()
{
    int a = 3, s;
    s = f(a);
    s = s + f(a);
    cout << s << endl;
    return 0;
}
int f(int n)
{
    static int a = 2;
    n += a++;
    return n;
}
```

- A、8
- B、9
- C、10
- D、11

**【参考答案】D（11）**

**解析：** 静态局部变量 a 保留上次值。第一次 f(3)：n=3+2=5，a→3；第二次 f(3)：n=3+3=6，a→4；s=5+6=11。

## 第 3 题

以下程序运行后，输出结果是（ ）。

```cpp
#include <iostream>
using namespace std;
int a = 8;
int fun(int b)
{
    int a = 15;
    a += b;
    cout << a << " ";
}
int main()
{
    int c = 10;
    fun(c);
    a += c;
    cout << a << endl;
    return 0;
}
```

- A、20 25
- B、25 10
- C、25 18
- D、10 18

**【参考答案】C（25 18）**

**解析：** fun 内局部 a=15，a+=b(10)=25，输出 25；main 中使用全局 a=8，a+=c(10)=18，输出 18。

## 第 4 题

以下程序运行后，输出结果是（ ）。

```cpp
#include <iostream>
using namespace std;
#define f(x) x * x * x
int main()
{
    int a = 4, s, t;
    s = f(a + 1);
    t = f((a + 1));
    cout << s << ',' << t << endl;
    return 0;
}
```

- A、10，64
- B、13，125
- C、125，13
- D、64，10

**【参考答案】B（13，125）**

**解析：** 宏只做文本替换。s=f(a+1)=a+1*a+1*a+1=4+4+4+1=13；t=f((a+1))=(a+1)*(a+1)*(a+1)=5*5*5=125。

## 第 5 题

程序实现调用函数 fun 求平均值，将程序补充完整，应选择（ ）。

```cpp
#include <iostream>
using namespace std;
int fun(int, int, int);
int main()
{
    int x, y, z;
    x = 4; y = 12; z = 6;
    ____; // 将程序补充完整

}
int fun(int i, int j, int k)
{
    int t;

```

- A、fun(x,y,z)

## 第 6 题

输入并运行以下程序，分析程序运行结果。

```cpp
#include <iostream>
using namespace std;
int p1();
int p2();
int a = 2;
int main()
{
    cout << "(1)a=" << a << endl;
    p1();
    p2();
    cout << "(4)a=" << a << endl;
}
int p1()
{
    a = a * a;
    cout << "(2)a=" << a << endl;
}
int p2()
{
    a = a * a * a;
    cout << "(3)a=" << a << endl;
}
```

**【参考答案】**

```
(1)a=2
(2)a=4
(3)a=64
(4)a=64
```

**解析：** a 是全局变量，各函数共享。p1 后 a=2*2=4；p2 后 a=4*4*4=64；main 再输出仍为 64。

## 第 7 题

输入并运行以下程序，程序运行结果是（ ）。

```cpp
#include <iostream>
using namespace std;
int f1();
int f2();
int x = 3;
int main()
{
    auto int x = 4;
    cout << "(1)x=" << x << endl;
    f1();
    f2();
    cout << "(4)x=" << x << endl;
}
int f1() { x += 10; cout << "(2)x=" << x << endl; }
int f2() { x += 10; cout << "(3)x=" << x << endl; }
```

- A、(1)x=4 (2)x=13 (3)x=13 (4)x=13
- B、(1)x=4 (2)x=13 (3)x=13 (4)x=4
- C、(1)x=4 (2)x=14 (3)x=24 (4)x=24
- D、(1)x=4 (2)x=13 (3)x=23 (4)x=4

**【参考答案】D**

**解析：** main 内局部 x=4 屏蔽全局 x；f1、f2 操作全局 x：3→13→23；回到 main 局部 x 仍为 4。

## 第 8 题

输入并运行以下程序，程序运行结果是（ ）。

```cpp
#include <iostream>
using namespace std;
int f(int);
int main()
{
    int i;
    for (i = 1; i <= 5; i++)
        f(i);
}
int f(int j)
{
    static int a = 100; /* 定义静态局部变量 */
    int k = 1;
    ++k;
    cout << a << "+" << k << "+" << j << "=" << a + k + j << endl;
    a += 10;
}
```

**【参考答案】**

```
100+2+1=103
110+2+2=114
120+2+3=125
130+2+4=136
140+2+5=147
```

**解析：** 静态局部 a 每次保留并 +10；k 每次进入函数都重置为 1，再 ++ 为 2；j 依次为 1~5。
