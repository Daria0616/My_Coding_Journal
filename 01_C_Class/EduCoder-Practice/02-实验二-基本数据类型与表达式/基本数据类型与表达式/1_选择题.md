## 第 1 题

C++ 语言源程序名的后缀是（ ）。

- A、.exe
- B、.c
- C、.obj
- D、.cpp

**【参考答案】D（.cpp）**

**解析：** C++ 源程序后缀为 `.cpp`；`.exe` 是可执行文件，`.c` 是 C 语言源文件，`.obj` 是编译生成的目标文件。

## 第 2 题

下列四组选项中，均是不合法的用户标识符的选项是（ ）。

- A、W　P_0　do
- B、b-a　goto　int
- C、float　la0　_A
- D、-123　abc　TEMP

**【参考答案】B**

**解析：** B 组中 `b-a` 含非法字符 `-`，`goto`、`int` 是关键字，三者都不能作标识符。
A 组中 W、P_0 合法（仅 do 非法）；C 组中 la0、_A 合法（仅 float 非法）；D 组中 abc、TEMP 合法（仅 -123 非法）。

## 第 3 题

在 C 语言中，合法的字符常量是（ ）。

- A、'\084'
- B、'\x43'
- C、'ab'
- D、"\0"

**【参考答案】B（'\x43'）**

**解析：** `'\x43'` 是十六进制转义字符常量。A 八进制转义不能出现数字 8；C 单引号内只能有一个字符（`ab` 多字符）；D 双引号括起的是字符串而非字符常量。

## 第 4 题

设 x、y 均为整型变量，且 x=8，y=5，则以下语句的输出结果是（ ）。

```cpp
cout << x-- << "," << ++y << endl;
```

- A、8, 5
- B、7, 5
- C、7, 6
- D、8, 6

**【参考答案】D（8, 6）**

**解析：** `x--` 是后置自减，先输出 x 当前值 8，再减 1；`++y` 是前置自增，y 先加 1 变为 6 再输出。故输出 `8, 6`。

## 第 5 题

下面程序的输出结果是（ ）。

```cpp
#include<iostream>
using namespace std;
int main()
{
    double d = 3.2;
    int x = 1.2, y;
    y = (x + 3.8) / 5.0;
    cout << d * y << endl;
    return 0;
}
```

- A、3
- B、3.2
- C、0
- D、3.07

**【参考答案】C（0）**

**解析：** `x=1.2` 赋给 int 截断为 1；`y=(1+3.8)/5.0=0.96`，赋给 int 截断为 0；`d*y=3.2*0=0`。

## 第 6 题

若 ch 为字符型变量，且值为 'A'，则 `(ch>='A' && ch<='Z') ? (ch+32) : ch` 的运行结果是（ ）。

- A、A
- B、a
- C、Z
- D、z

**【参考答案】B（a）**

**解析：** 'A' 位于大写字母区间内，条件成立，执行 `ch+32`，大写字母加 32 转为对应小写字母 'a'。

## 第 7 题

设 a=1, b=2, c=3, d=4，则表达式 `a>b?a:c<d?c:d` 的结果为（ ）。

- A、1
- B、2
- C、3
- D、4

**【参考答案】C（3，三元运算符右结合）**

**解析：** 条件运算符右结合，等价于 `a>b ? a : (c<d ? c : d)`。`a>b` 为假，计算 `c<d?c:d`，`c<d` 为真，取 c=3。

## 第 8 题

以下所列的 C 语言常量中，错误的是（ ）。

- A、0xFF
- B、1.2e5.0
- C、2L
- D、'\72'

**【参考答案】B（1.2e5.0）**

**解析：** 科学计数法 `e` 后面的指数必须是整数，`5.0` 是小数，写法非法。0xFF 是十六进制整数，2L 是长整型，'\72' 是八进制转义字符常量。

---

## 第 9 题

下列选项中，合法的 C 语言关键字是（ ）。

- A、VAR
- B、cher
- C、integer
- D、default

**【参考答案】D（default）**

**解析：** `default` 是 switch 语句中的关键字；VAR、cher、integer 都不是 C 语言关键字。

## 第 10 题

下列定义变量的语句中错误的是（ ）。

- A、int _int;
- B、double int_;
- C、char For;
- D、float 0SS;

**【参考答案】D（float 0SS;）**

**解析：** 标识符不能以数字开头，`0SS` 非法。其余：下划线可开头（_int），关键字后加下划线合法（int_），大小写不同 For 不等于关键字 for。
