## 第 1 题

有以下程序，程序运行后的输出结果是（ ）。

```cpp
#include <iostream>
using namespace std;
int main()
{
    int n = 2, k = 1;
    while (k++ && n++ > 2);
    cout << k << " " << n << endl;
}
```

- A、2 3
- B、1 3
- C、2 2
- D、1 2

**【参考答案】A（2 3）**

**解析：** `k++` 后置，先用 k=1 为真，再自增到 2；`n++>2` 先用 n=2 比较 `2>2` 为假，n 自增到 3。`&&` 整体为假，循环结束，输出 2 3。

## 第 2 题

以下程序运行后的输出结果是（ ）。

```cpp
#include <iostream>
using namespace std;
int main()
{
    int a = 1, b = 8;
    do {
        b = b / 2;
        a += b;
    } while (b > 1);
    cout << a << endl;
}
```

- A、1
- B、5
- C、8
- D、9

**【参考答案】C（8）**

**解析：** do-while 先执行后判断：b=8→4，a=5；b=4→2，a=7；b=2→1，a=8；此时 b=1 不大于 1，结束循环，输出 8。

## 第 3 题

有以下程序，程序运行后的输出结果是（ ）。

```cpp
int main()
{
    int f, f1, f2, i;
    f1 = 1; f2 = 2;
    for (i = 2; i <= 4; i++)
    {
        f = f1 + f2;
        cout << f << " ";
        f1 = f2;
        f2 = f;
    }
    cout << endl;
}
```

- A、1 2 3
- B、2 3 3
- C、3 5 5
- D、3 5 8

**【参考答案】D（3 5 8）**

**解析：** 斐波那契递推 `f=f1+f2`：i=2 得 3，i=3 得 5，i=4 得 8，输出 3 5 8。

## 第 4 题

以下程序段的输出结果是（ ）。

```cpp
for (i = 0; i < 4; i++, j++);
for (k = 1; k < 3; k++) cout << "*";
```

- A、********
- B、****
- C、**
- D、*

**【参考答案】C（**）**

**解析：** 第一个 for 以分号结尾，是空循环，不输出；第二个 for k=1、2 共执行两次，输出两个 `*`，即 `**`。

## 第 5 题

执行下面的程序后，a 的值为（ ）。

```cpp
int main()
{
    int a, b;
    for (a = 1, b = 2; a <= 100; a++)
    {
        if (b >= 20) break;
        if (b % 3 == 2) { b += 3; continue; }
        b -= 5;
    }
}
```

- A、5
- B、6
- C、7
- D、8

**【参考答案】C（7）**

**解析：** b 满足 `b%3==2` 时就 +3 并 continue：2→5→8→11→14→17→20。下一轮 a=7 时 b=20，`b>=20` 触发 break，此时 a=7。
