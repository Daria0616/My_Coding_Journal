## 4-2
下列程序的输出结果是 ____。

```c
void swap(int x, int y)
{
    int t;
    t = x; x = y; y = t;
    return;
}
void main(void)
{
    int a = 3, b = 2;
    swap(a, b);
    printf("%d#%d#", a, b);
    return;
}
```

【作答】**3#2#**

> 解析：传值调用，swap 内部交换的是形参副本，实参 a、b 不受影响。

## 4-3
写出下列程序的运行结果 ____。

```c
#include <stdio.h>
int x;
int f( );
int main(void)
{
    int a = 1;

    x = a;
    a = f( );
    {
        int b = 2;
        b = a + b;
        x = x + b;
    }
    printf("%d %d", a, x);

    return 0;
}

int f( )
{
    int x = 4;
    return x;
}
```

【作答】**4 7**

> 解析：f 内的 x 是局部变量，返回 4；全局 x 先为 1，块内 b=4+2=6，x=1+6=7。

## 4-4
阅读以下程序并回答问题。

```c
#include<stdio.h>
int f1(int n)
{        static int r = 1;
         return r = r * n;
}
int main(void)
{
         int i;
         for(i = 1; i <= 6; i++)
                printf("%d\n", f1(i));
         return 0;
}
```

- （1）程序运行时，第 2 行输出 ____。
- （2）程序运行时，第 4 行输出 ____。

【作答】空 1：**2**；空 2：**24**

> 解析：r 为静态局部变量，保留上次结果：f1(1)=1，f1(2)=2，f1(3)=6，f1(4)=24，f1(5)=120，f1(6)=720。

## 4-5
写出以下程序的运行结果。

```c
#include <stdio.h>
int f2(int n)
{
    if(n == 1){
        return 1;
    }else{
        return n * f2(n-1);
    }
}
int main(void)
{
    int i;

    for(i = 1; i <= 6; i++){
        printf("%d\n", f2(i));
    }
    return 0;
}
```

- 第 3 行输出：____
- 第 5 行输出：____

【作答】空 1：**6**；空 2：**120**

> 解析：f2 为递归阶乘：1，2，6，24，120，720。
