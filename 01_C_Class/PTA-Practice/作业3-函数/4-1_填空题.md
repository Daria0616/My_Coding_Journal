## 4-1
某函数有返回值，某次调用该函数结束后，该函数能够返回的值的个数为 ____ 个（填数字）。

【作答】**1**

> 评测：✅ 正确。解析：一次函数调用通过 `return` 只能带回**一个**返回值；要带回多个结果需通过指针/数组参数或全局变量。

## 4-2
下列程序的输出结果是 ____。

```c
void swap(int x, int y)
{
    int t;
    t = x; x = y; y = t;
    return;
}
void main(void)
{
    int a = 3, b = 2;
    swap(a, b);
    printf("%d#%d#", a, b);
    return;
}
```

【作答】**3#2#**

> 评测：✅ 正确（已编译运行，输出 `3#2#`）。解析：传值调用，`swap` 内部交换的是形参 x、y 的副本，实参 a、b 不受影响，故仍为 3、2。

## 4-3
写出下列程序的运行结果 ____。

```c
#include <stdio.h>
int x;
int f( );
int main(void)
{
    int a = 1;

    x = a;
    a = f( );
    {
        int b = 2;
        b = a + b;
        x = x + b;
    }
    printf("%d %d", a, x);

    return 0;
}

int f( )
{
    int x = 4;
    return x;
}
```

【作答】**4 7**

> 评测：✅ 正确（已编译运行，输出 `4 7`）。解析：f 内的 `x` 是局部变量，屏蔽全局 x，返回 4，故 `a=4`；全局 x 先被赋为 1，块内 `b=a+b=4+2=6`，`x=x+b=1+6=7`。

## 4-4
阅读以下程序并回答问题。

```c
#include<stdio.h>
int f1(int n)
{        static int r = 1;
         return r = r * n;
}
int main(void)
{
         int i;
         for(i = 1; i <= 6; i++)
                printf("%d\n", f1(i));
         return 0;
}
```

- （1）程序运行时，第 2 行输出 ____。
- （2）程序运行时，第 4 行输出 ____。

【作答】空 1：**2**；空 2：**24**

> 评测：✅ 正确（已编译运行）。解析：`r` 为静态局部变量，只初始化一次并保留上次结果：f1(1)=1，f1(2)=2，f1(3)=6，f1(4)=24，f1(5)=120，f1(6)=720。第 2 行为 2，第 4 行为 24。

## 4-5
写出以下程序的运行结果。

```c
#include <stdio.h>
int f2(int n)
{
    if(n == 1){
        return 1;
    }else{
        return n * f2(n-1);
    }
}
int main(void)
{
    int i;

    for(i = 1; i <= 6; i++){
        printf("%d\n", f2(i));
    }
    return 0;
}
```

- 第 3 行输出：____
- 第 5 行输出：____

【作答】空 1：**6**；空 2：**120**

> 评测：✅ 正确（已编译运行）。解析：f2 为递归阶乘，输出依次为 1，2，6，24，120，720；第 3 行为 6，第 5 行为 120。

## 4-6
构成 C 语言程序的基本单位是 ____。

【作答】**函数**

> 评测：✅ 正确。解析：C 程序由若干**函数**组成，`main` 是程序执行的入口；函数是 C 程序的基本组成单位。

## 4-7
C 语言中的变量，按作用域范围可分为两种，即 ____ 和全局变量。

【作答】**局部变量**

> 评测：✅ 正确。解析：按作用域分为**局部变量**（定义在函数/块内，作用域局限于该块）和全局变量（定义在函数外，作用域从定义处到文件尾）。

## 4-8
C 语言中函数的参数分为 ____ 和 ____。

【作答】空 1：**形式参数**；空 2：**实际参数**

> 评测：✅ 正确。解析：定义函数时括号内的是**形式参数（形参）**；调用函数时传入的是**实际参数（实参）**，传值调用时实参把值复制给形参。
