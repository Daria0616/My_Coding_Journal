# 作业3（函数）· 单选题

## 2-1
C 语言程序中的函数是由（  ）组成。

- A. 函数名和参数
- B. 函数名和函数体
- C. 返回值类型和函数名
- D. 函数首部和函数体

【作答】D

> 评测：✅ 正确。解析：函数由**函数首部**（返回值类型 + 函数名 + 形参表）和**函数体**两部分组成；A、B、C 都只涵盖了其中一部分。

## 2-2
未指定存储类别的局部变量，其隐含的存储类别为（  ）。

- A. auto
- B. static
- C. extern
- D. register

【作答】A

> 评测：✅ 正确。解析：局部变量默认 `auto`（自动存储类别），进入所在块时在栈上分配、退出块时自动释放；`static` 为静态局部变量，`extern` 用于声明外部全局变量，`register` 为寄存器变量。

## 2-3
在一个源文件中定义的全局变量，其作用域为（  ）。

- A. 本文件的全部范围
- B. 本程序的全部范围
- C. 本函数的全部范围
- D. 从定义该变量的位置开始至本文件结束

【作答】D

> 评测：✅ 正确。解析：全局变量的作用域是**从定义处开始到本文件结束**；若在定义之前使用，需用 `extern` 提前声明。跨文件使用才属于整个程序范围。

## 2-4
在传值调用中，要求（  ）。

- A. 形参和实参类型任意，个数相等
- B. 实参和形参类型都完全一致，个数相等
- C. 实参和形参对应的类型一致，个数相等
- D. 实参和形参对应的类型一致，个数任意

【作答】C

> 评测：✅ 正确。解析：传值调用要求实参与形参**个数相等、对应位置类型一致**（允许隐式类型转换）；个数必须一一对应，不能任意。

## 2-5
关于变量的生存期和作用域，下列说法正确的是（  ）。

- A. 局部变量的作用范围是从定义处到源文件结束。
- B. 全局变量作用范围是整个文件。
- C. 变量生命周期是指变量从定义开始分配存储单元到运行结束存储单元被回收的整个过程。
- D. 若局部变量与全局变量同名，全局变量优先。

【作答】C

> 评测：✅ 正确。解析：C 是生存期（生命周期）的定义。A 错：局部变量作用域到所在**块**结束，不是文件尾；B 不够准确：全局变量从定义处起生效；D 错：同名时**局部变量屏蔽全局变量**，局部优先。

## 2-6
在使用数学函数时，要为程序添加头文件（  ）。

- A. 不添加
- B. `#include<stdio.h>`
- C. `#include<math.h>`
- D. 以上都不对

【作答】C

> 评测：✅ 正确。解析：`sqrt`、`fabs`、`pow` 等数学函数声明在 `math.h`；`stdio.h` 是输入输出函数头文件。

## 2-7
C 语言中函数返回值的类型是由以下（  ）决定的。

- A. 函数定义时指定的类型
- B. return 语句中的表达式类型
- C. 调用该函数时的实参的数据类型
- D. 形参的数据类型

【作答】A

> 评测：✅ 正确。解析：返回值类型由**函数首部定义时指定的类型**决定；`return` 表达式的值会按该类型转换后带回，与实参、形参类型无关。

## 2-8
如果函数类型被省略，则这个函数类型被默认定义为（  ）。

- A. void
- B. int
- C. char
- D. float

【作答】B

> 评测：✅ 正确（教材/旧式 C 口径）。解析：按传统 C 语言规定，函数返回类型省略时默认为 `int`。注意：现代标准 C/C++ 已不允许省略返回类型，考试以教材口径为准。

## 2-9
以下正确的描述是：在 C 语言程序中（  ）。

- A. 函数的定义可以嵌套，但函数的调用不可以嵌套
- B. 函数的定义和函数的调用均不可以嵌套
- C. 函数的定义和函数的调用均可以嵌套
- D. 函数的定义不可以嵌套，但函数的调用可以嵌套

【作答】D

> 评测：✅ 正确。解析：C 语言**函数定义不能嵌套**（函数内不能再定义另一个函数），但**函数调用可以嵌套**（如 `f(g(x))`，函数内调用别的函数）。

## 2-10
C 语言的编译系统对宏命令的处理（  ）。

- A. 在程序运行时进行的
- B. 在对源程序中其他语句正式编译之前进行的
- C. 在程序连接时进行的
- D. 和 C 程序中的其他语句同时进行编译的

【作答】B

> 评测：✅ 正确。解析：宏替换由**预处理程序**在正式编译之前完成（文本展开），不运行程序、也不在连接阶段处理。

## 2-11
在“文件包含”预处理语句的使用过程中，当 `#include` 后面的文件名用双引号括起来时，寻找被包含文件的方式是（  ）。

- A. 直接按系统设定的标准方式搜索目录
- B. 先在源程序所在目录搜索，再按系统设定的标准方式搜索
- C. 仅仅搜索源程序所在目录
- D. 仅仅搜索当前目录

【作答】B

> 评测：✅ 正确。解析：双引号 `#include "file.h"` 先在**源文件所在目录**查找，找不到再按系统标准目录搜索；尖括号 `<file.h>` 只搜索系统标准目录。

## 2-12
关于 return 语句的描述，错误的是（  ）。

- A. 函数的定义中可以没有 return 语句
- B. 一条 return 语句可以返回多个变量或常量的值
- C. 函数中可以出现多个 return 语句
- D. 执行 return 语句后，立刻结束函数的调用

【作答】B

> 评测：✅ 正确（题目要求选出**错误**描述）。解析：一条 `return` 只能带回**一个**返回值，不能同时返回多个，故 B 错误。A：`void` 函数可以没有 return；C：一个函数可有多个 return 分支；D：执行 return 后立即结束本次函数调用。

## 2-13
递归函数将出现无限递归的情况的是（  ）。

- A. 递归函数没有返回值
- B. 递归函数缺少明确的终止条件
- C. 递归函数使用了全局变量
- D. 递归函数没有参数

【作答】B

> 评测：✅ 正确。解析：递归必须有明确的**递归出口（终止条件）**；缺少终止条件时递归一直向下进行，无法返回，形成无限递归。

## 2-14
对于函数原型（函数声明），声明不接受任何参数且返回整型的函数的是（  ）。

- A. `int f();`
- B. `int f(int);`
- C. `void f(int);`
- D. `void f();`

【作答】A

> 评测：✅ 正确（教材口径）。解析：返回整型排除 C、D（`void` 无返回值）；B 带一个整型形参；只有 A 返回整型。补充：严格按 C 标准，`int f();` 表示“参数类型未指定”，明确无参应写作 `int f(void);`，但本题选项中无后者，按教材选 A。

## 2-15
以下函数调用语句中实参的个数为（  ）。

```c
fun1((a, a-1, a-3), (b, b+4));
```

- A. 1
- B. 2
- C. 3
- D. 5

【作答】B

> 评测：✅ 正确。解析：数实参只看函数最外层括号内、用逗号分隔的参数，共 **2 个**：`(a, a-1, a-3)` 和 `(b, b+4)`。内层括号里的逗号是**逗号表达式**运算符（依次求值、取最后一个值）：第一个实参的值为 `a-3`，第二个实参的值为 `b+4`；它们不是实参分隔符，因此不计入实参个数。故实参个数为 2，选 B。
