## 2-3 ⚠️ 错题

若有变量定义 `int a = 1, b = 2, c = 3, d = 4;` 则表达式 `a < b ? a : b < c ? b : c < d ? c : d` 的值为（  ）。

- A、1
- B、2
- C、3
- D、4

- ❌ **作答错误**
- ✅ **正确答案**：A（1）

**解析：** 三目运算符右结合，等价 `a<b ? a : (b<c ? b : (c<d ? c : d))`。`a<b`（1<2）为真，直接取 `a=1`。

## 2-34 ⚠️ 错题

写出下面程序在 Dev C++ 中的输出结果（  ）。

```c
main()
{
    int I, j;
    I=16;
    j=(I++)+I;
    printf("%d  ", j);
    I=15;
    printf("%d  %d", ++I, I);
}
```

- A、32 16 15
- B、33 16 16
- C、34 16 15
- D、34 16 16

- ❌ **作答错误**
- ✅ **正确答案**：B（33 16 16）

**解析：** `I=16; j=(I++)+I;` 后置自增先取 16、I 变 17，再加当前 I=17，`j=33`；
`I=15; ++I` 先增为 16，两个参数都为 16，输出 `16 16`。
