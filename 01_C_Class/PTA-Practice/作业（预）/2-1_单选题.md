## 2-1

在程序中固定不变的值称为（  ）。

- A、变量
- B、常量
- C、关键字
- D、数组

【参考答案】B ✓

**解析：** 程序中固定不变、运行时不能被修改的值叫常量；变量是可以改变的量，关键字是语言预留的保留字，数组是存放一组同类型数据的聚合类型。

## 2-2

- A、0
- B、1
- C、2
- D、3

【参考答案】B ✓

## 2-3 ⚠️ 错题

若有变量定义 `int a = 1, b = 2, c = 3, d = 4;` 则表达式 `a < b ? a : b < c ? b : c < d ? c : d` 的值为（  ）。

- A、1
- B、2
- C、3
- D、4

- ❌ **作答错误**
- ✅ **正确答案**：A（1）

**解析：** 三目运算符右结合，等价 `a<b ? a : (b<c ? b : (c<d ? c : d))`。`a<b`（1<2）为真，直接取 `a=1`。

## 2-32

写出下面程序的输出结果（  ）。

```c
main()
{
    int x, y, z;
    x = y = 1;
    z = x++ - 1;
    printf("%d,%d\t", x, z);
    z += -x++ + (++y || ++z);
    printf("%d,%d", x, z);
}
```

- A、2,0 3,-1
- B、2,1 3,0
- C、2,0 2,1
- D、2,1 0 ,1

【参考答案】A、2,0 3,-1 ✓

**解析：** 第一段：`x=y=1`，`z=x++-1` 后置自增先取 1，`z=1-1=0`，x 变 2，打印 `2,0`。第二段：`z += -x++ + (++y || ++z)`，本机 gcc（-O0）实测第二段后 `x=3、z=-1`，打印 `3,-1`，对应选项 A。注：该表达式在同一行对 x、y、z 多次自增，严格来说属未定义行为，不同编译器/优化级别结果可能不同；本题平台判定为 A。

## 2-33

写出下面程序的输出结果（  ）。

```c
main()
{
    int x=40, y=4, z=4;
    x = y == z;
    printf("%d  ", x);
    x = x == (y-z);
    printf("%d", x);
}
```

- A、4 0
- B、4 1
- C、1 1
- D、1 0

【参考答案】D ✓

**解析：** 第一句 `x = y == z`，关系运算优先于赋值，`y==z`（4==4）为真得 1，故 x=1，打印 1；第二句 `x = x == (y-z)`，`y-z=0`，`x==0`（1==0）为假得 0，故 x=0，打印 0。输出 `1 0`。
