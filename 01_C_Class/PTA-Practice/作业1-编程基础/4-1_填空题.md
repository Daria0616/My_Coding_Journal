## 4-1
在 C 语言中，字符常量 `'A'` 在内存中占 ____ 个字节，字符串常量 `"A"` 占 ____ 个字节。

- 空 1：**1**
- 空 2：**2**

> 解析：字符常量占 1 个字节；字符串 `"A"` 除字符 `A` 外还占 1 个字节存放结束符 `'\0'`，共 2 字节。

## 4-2
设有如下声明和语句：

```c
int x=2, y, z=5;
scanf("%d", &y);
y=z--||scanf("%d", &z)&&x++;
```

该程序段执行时，若从键盘输入的数据是 `4 3`（空格分隔），则变量 z 的值为 ____。

【参考答案】**4**

> 解析：`z--` 先用后减，原值 5 为真，`||` 短路，右侧不再执行；`x++` 也不执行。
> 注意：`z--` 使 z 由 5 变为 4，故最终 z=4。

## 4-3
执行如下 C 语句后，x 和 y 的值分别为 ____，____。（结果保留两位小数）

```c
float x = (float) 10 / 3;
float y = (float) (10 / 3);
```

- 空 1：**3.33**
- 空 2：**3.00**

> 解析：`(float)10/3` 先把 10 转成 float 再除，得 3.333…；`(float)(10/3)` 先做整型除法 10/3=3，再转 float，得 3.00。

## 4-4
阅读下列程序代码，写出运行结果。

```c
#include<stdio.h>
int main()
{
    int a,b;
    a=sizeof(3+5.0);
    b=sizeof 3+5.0;
    printf("%d,%d,%d\n",a,b,sizeof("china"));
    return 0;
}
```

运行结果为：____

【参考答案】**8,9,6**

> 解析：`3+5.0` 为 double，sizeof 为 8；`sizeof 3` 是 int 占 4，再加 5.0 得 9（按 double 计算后取整）；
> `"china"` 含 5 个字符加 `'\0'`，sizeof 为 6。

## 4-5
执行语句 `printf("%d", 1/2);` 的输出结果是 ____；执行 `printf("%f", 1.0/2);` 的输出结果是 ____。

- 空 1：**0**
- 空 2：**0.500000**

> 解析：`1/2` 是整型除法得 0；`1.0/2` 为浮点除法得 0.5，`%f` 默认输出 6 位小数。
