## 2-1
有以下程序段：

```c
int a = 10, b = 20;
printf("%d, %d", a, b);
```

若要求输出结果为“20, 10”，则应将 printf 语句改为（  ）。

- A. `printf("%d, %d", &a, &b);`
- B. `printf("%d, %d", (b, a));`
- C. `printf("%d, %d", b, a);`
- D. `printf("%d, %d", &b, &a);`

【参考答案】C

**解析：** printf 按实参顺序输出，把两个实参交换成 `b, a` 即先打 b 再打 a。`&a`、`&b` 是取地址，配合 `%d` 输出的是地址而不是数值；逗号表达式 `(b, a)` 只取最后一个 a，不能交换两个值。

## 2-2
设有说明：`char c; int x; double z;`，则表达式 `c*x+z` 值的数据类型为（  ）。

- A. float
- B. int
- C. char
- D. double

【参考答案】D

**解析：** 混合运算时按"就高不就低"自动提升：char、int 先参与整型运算，一旦遇到 double 型 z，整个表达式提升为 double。

## 2-3
下列两条语句 `int c1=5, c2=4, c3; c3=1.0/c2*c1;` 执行后变量 c3 中的值是（  ）。

- A. 0.5
- B. 0
- C. 1
- D. 2

【参考答案】C

**解析：** `1.0/c2` 是浮点除法 = 0.25，再 `*c1` = 1.25；c3 是 int，赋值时截断小数部分，得到 1。

## 2-4
C 语言中基础的数据类型不包括（  ）。

- A. 结构体类型
- B. 整型
- C. 浮点型
- D. 字符型

【参考答案】A

**解析：** 整型、浮点型、字符型是 C 的基础（内置）类型；结构体是由基础类型组合成的构造类型，不属于基础类型。

## 2-5
执行以下代码，输出的结果是（  ）。

```c
#include <stdio.h>
int main(){
    double x = 5 / 2 * 1.5;
    printf("%.2f\n", x);
    return 0;
}
```

- A. 3.75
- B. 3.00
- C. 1.00
- D. 3
- E. 2
- F. 1
- G. 1.50
- H. 2.25

【参考答案】B

**解析：** `5/2` 两个都是整数，先做整数除法得 2，再 `*1.5` = 3.0；`%.2f` 输出 3.00。注意不是 5/2=2.5。

## 2-6

## 2-9

- A. `_count`
- B. `2number`

## 2-10
执行下列代码后，a 的值是多少？

```c
int a=10;
a += a -= a *= 2;
```

- A. -20
- B. 0
- C. 10
- D. -10

【参考答案】B

**解析：** 复合赋值运算符**右结合**，从右往左算：`a*=2` → a=20；`a-=20` → a=0；`a+=0` → a=0。

## 2-11
以下关于 C 语言表达式的叙述中，正确的是（  ）。

- A. 赋值表达式“a = b = c”是非法的
- B. 关系表达式的结果是整数 0 或 1
- C. 逻辑表达式“5 && 0”的结果是 0，类型为浮点型
- D. 逗号表达式“a=3, a*2, a+5”的值为 8

【参考答案】B

**解析：** 关系表达式成立为 1、不成立为 0，结果是整型。A 连续赋值 `a=b=c` 合法；C 逻辑表达式结果是整型，不是浮点型；D 逗号表达式虽取最后一项，但本题单选正确项为 B。

## 2-12
以下关于类型转换的叙述，错误的是（  ）。

- A. 当 int 与 float 进行运算时，int 会隐式转换为 float
- B. 强制类型转换运算符“(类型名)”不会改变变量本身的类型
- C. char 类型与 int 类型运算时，char 总是先转换为 unsigned int
- D. 赋值运算时，右侧表达式的值会自动转换为左侧变量的类型

【参考答案】C

**解析：** char 与 int 运算时提升为 int（是否无符号取决于平台和字符集），并不是"总是 unsigned int"，所以 C 错误。B 对：强制转换只得到一个临时值，变量本身类型不变。

## 2-14

## 2-15
以下程序的输出结果是（  ）。

```c
int main(void)
{   int  a=5, b=7;
    a=a+b;
    b=a-b;
    a=a-b;
    printf("%d-%d\n", a, b );
    return 0;
}
```

- A. 7-5
- B. 5-5
- C. 5-7
- D. 7-7

【参考答案】A

**解析：** 这是不用临时变量的加减交换：a=5+7=12；b=12-7=5；a=12-5=7。最后 a=7、b=5，输出 7-5。

## 2-16
下列程序段的输出结果是（  ）。

```c
int main(void)
{   float  a;
    int  b=9;
    a=9/2;
    b=b/2*a;
    printf("%f,%d\n",a,b);
    return 0;
}
```

- A. 2.000000,4
- B. 3.000000,8
- C. 4.000000,16
- D. 5.000000,20

【参考答案】C（4.000000,16）✓

**解析：** `9/2` 是整数除法得 4，故 `a=4.000000`；`b=9/2=4`（整数除），再 `4*a=4*4.0=16`，即 `b=16`，对应选项 C。

## 2-17
执行以下程序段后，输出（  ）。

```c
int number;
number = 890;
printf("%d-%d-%d\n", number%10, number/10%10, number/100);
```

- A. 8-9-0
- B. 0-9-8
- C. 8-0-9
- D. 9-8-0

【参考答案】B

**解析：** 拆各位：个位 `890%10=0`；十位 `890/10%10=89%10=9`；百位 `890/100=8`，输出 0-9-8。

## 2-18
下列语句中，不能连续输出 3 个值的是（  ）。

- A. `cout<<x<<y<<z;`
- B. `cout<<x,y,z;`
- C. `cout<<x; cout<<y; cout<<z;`
- D. `cout<<(x,y,z)<<(x,y,z)<<(x,y,z);`

【参考答案】B

**解析：** B 里的逗号是逗号运算符，`cout<<x,y,z` 实际等价于 `(cout<<x), y, z`，只输出 x；A、C 都能依次输出三个值，D 每次括号取 z 也能输出。

## 2-19
下列程序代码，正确的输出结果是（  ）。

```c++
int a=0xff;
int b=017;
cout<<a<<","<<b<<endl;
```

- A. 0xff,017
- B. ff,17
- C. 255,15
- D. 255,17

【参考答案】C

**解析：** `0xff` 是十六进制 = 255；`017` 是八进制（前导 0）= 1×8+7 = 15；cout 默认按十进制输出。

## 2-20
设有定义“int k=0;”，下列选项的 4 个表达式中与其他 3 个表达式的值不相同的是（  ）。

- A. `k++`
- B. `k+=1`
- C. `++k`
- D. `k+1`

【参考答案】A

**解析：** `k++` 是后置自增，**表达式取自增前的旧值 0**；而 `k+=1`、`++k`、`k+1` 的表达式值都是 1，所以 A 与其余三个不同。
