## 5-1 两个整数的和

下列程序应读入两个整数，然后输出这两个整数的和。请填空使程序完整。

```c
#include <stdio.h>

int main()
{   int a, b;
    scanf("%d %d", ____);
    printf("%d", ____);
    return 0;
}
```

- 空 1：**`&a, &b`**
- 空 2：**`a + b`**

【结果】答案正确。

## 5-2 奇数偶数

输入一个整数，判断是奇数还是偶数。偶数输出 O，奇数输出 J。

```c
#include <stdio.h>
int main()
{
    int num;

    ____;

    if (____)
        printf("O");
    else
        printf("J");
    return 0;
}
```

- 空 1：**`scanf("%d", &num)`**
- 空 2：**`num % 2 == 0`**

【结果】答案正确。

## 5-3 判断大写字母 ⚠️ 错题

输入一个英文字符，判断是否是大写。是则输出 Y，否则输出 N。

```c
#include <stdio.h>
int main()
{
    char ch;

    ____;
    if(____)
    {
        printf("Y\n");
    }
    else
    {
        printf("N\n");
    }

    return 0;
}
```

### 空 1
- ❌ **当时错误答案**：`scanf("%d", &ch)`（得分 0/2，类型用错：`%d` 按整型读入字符）
- ✅ **正确答案**：`scanf(" %c", &ch)`
  > 注意 `%c` 前的空格用于跳过输入缓冲区中的空白字符（回车/空格）。

### 空 2
- ✅ **正确答案**：`ch >= 'A' && ch <= 'Z'`

【结果】部分正确，本题 3/5。
