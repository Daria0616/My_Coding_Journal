## 5-1 两个整数的和

下列程序应读入两个整数，然后输出这两个整数的和。请填空使程序完整。

```c
#include <stdio.h>

int main()
{   int a, b;
    scanf("%d %d", ____);
    printf("%d", ____);
    return 0;
}
```

- 空 1：**`&a, &b`**
- 空 2：**`a + b`**

**解析：** scanf 需要变量的**地址**才能把读入的值写进去，所以传 `&a, &b`；printf 第二个空直接放求和表达式 `a + b`，由 `%d` 输出。

【结果】答案正确。

## 5-2 奇数偶数

输入一个整数，判断是奇数还是偶数。偶数输出 O，奇数输出 J。

```c
#include <stdio.h>
int main()
{
    int num;

    ____;

    if (____)
        printf("O");
    else
        printf("J");
    return 0;
}
```

- 空 1：**`scanf("%d", &num)`**
- 空 2：**`num % 2 == 0`**

**解析：** 先读入整数 num；能被 2 整除即偶数，判断条件 `num % 2 == 0` 成立输出 O，否则输出 J。

【结果】答案正确。

## 5-3 判断大写字母 ⚠️ 错题

输入一个英文字符，判断是否是大写。是则输出 Y，否则输出 N。

```c
#include <stdio.h>
int main()
{
    char ch;

    ____;
    if(____)
    {
        printf("Y\n");
    }
    else
    {
        printf("N\n");
    }

    return 0;
}
```

### 空 1
- ❌ **当时错误答案**：`scanf("%d", &ch)`（得分 0/2，类型用错：`%d` 按整型读入字符）
- ✅ **正确答案**：`scanf(" %c", &ch)`
  > 注意 `%c` 前的空格用于跳过输入缓冲区中的空白字符（回车/空格）。

### 空 2
- ✅ **正确答案**：`ch >= 'A' && ch <= 'Z'`

**解析：** 字符必须用 `%c` 读入，不能用 `%d`；判断大写字母就是看字符是否落在 `'A'` 到 `'Z'` 的区间内，两个条件用 `&&` 同时成立。

【结果】部分正确，本题 3/5。

## 5-4 完善程序，使程序在两行输出

```c
#include <stdio.h>
int main()
{    int a,b;
    a=8;
    b=9;
    printf("____\n", a, a, a*a);   /* 输出 8*8=64 */
    printf("%d*%d=%d\n", ____);    /* 输出 8*9=72 */
    return 0;
}
```

- 空 1：**`%d*%d=%d`**
- 空 2：**`a, b, a*b`**

**解析：** 第一行三个实参是 `a, a, a*a`，格式串对应三个 `%d`，中间用 `*` 和 `=` 连接；第二行要输出 `8*9=72`，实参依次放被乘数 a、乘数 b、乘积 `a*b`。

【结果】答案正确。
