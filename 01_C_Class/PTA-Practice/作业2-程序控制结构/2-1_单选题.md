## 2-2

- A. 2
- B. 3

- D. 5


## 2-11
运行以下程序后，如果从键盘上输入 `China#` 回车，则输出结果为（  ）。

```c
int main( )
{  int v1=0, v2=0;
   char ch;
   while((ch=getchar( ))!='#')
   switch(ch)
   { case 'a':
     case 'h':
     default: v1++; break;
     case 'i': v2++;
   }
   cout<<v1<<","<<v2<<endl;
   return 0;
}
```

- A. 4,0
- B. 4,1
- C. 5,0
- D. 5,1

【参考答案】B

> 解析：字符 C、h、a、n 走 default 计入 v1（v1=4）；字符 i 计入 v2（v2=1）。
