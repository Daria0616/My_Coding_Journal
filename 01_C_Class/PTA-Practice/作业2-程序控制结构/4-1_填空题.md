## 4-1
有以下程序：

```c
#include <stdio.h>
main()
{ int n=2, k=0;
  while(k++ && n++>2) ;
  printf("%d %d\n", k, n) ;
}
```

程序运行后的输出结果是 k=____，n=____。

- 空 1：**1**
- 空 2：**2**

> 解析：`k++` 先用后增，初值 k=0 为假，`&&` 短路，`n++>2` 不执行；循环结束后 k 已自增为 1，n 保持 2。

## 4-2
有以下程序：

```c
#include <stdio.h>
main()
{ int a=1,b=2,c=3,d=0;
  if (a==1 && b++==2)
    if (b!=2 || c--!=3)
      printf("%d,%d,%d\n",a,b,c);
    else printf("%d,%d,%d\n",a,b,c);
  else printf("%d,%d,%d\n",a,b,c);
}
```

程序运行后输出结果是 a=____，b=____，c=____。

- 空 1：**1**
- 空 2：**3**
- 空 3：**3**

> 解析：`a==1` 为真且 `b++==2` 为真（b 变为 3）；进入内层 if，`b!=2` 为真，`||` 短路，`c--` 不执行，c 保持 3。

## 4-3
若 a 是数值类型，则逻辑表达式 `(a==1) || (a!=1)` 的值是 ____。

【参考答案】**1**

> 解析：两个条件必有一个成立，逻辑或恒为真，结果为 1。

## 4-4
当 a=1，b=3，c=5，d=4 时，执行下面一段程序后，x 的值为 ____。

```c
if(a<b)
    if(c<b)  x=1;
    else
        if(a<c)
            if(b<d)  x=2;
            else  x=3;
        else  x=6;
else  x=7;
```

【参考答案】**2**

> 解析：`a<b` 真；`c<b`（5<3）假；`a<c`（1<5）真；`b<d`（3<4）真，故 x=2。

## 4-5
执行下面的程序后，b 的值为 ____。

```c
int main( )
{
    int a , b;
    for( a=1 , b=1 ; a<=100; a++)
    { if(b>=20) break;
      if(b%3 == 1)
      { b+=3;
        continue;
      }
      b-=5;
    }
}
```

【参考答案】**22**

> 解析：b 从 1 开始，每次满足 `b%3==1` 就 +3 并 continue；依次为 1→4→7→10→13→16→19→22，
> 当 b=22 时满足 `b>=20` 跳出循环。
