# PTA-Practice（PTA 平台作业与测试整理）

> 平台：https://pintia.cn/problem-sets/dashboard
> 整理规则：编程题按语言存后缀——纯 C（`stdio.h`/`scanf`/`printf`）存 `.c`，C++（`iostream`/`cin`/`cout`）存 `.cpp`；顶部块注释写题目要求 / 输入格式 / 输出格式 / 样例；选择题、填空题、程序填空题存 `.md`。
> 文件名：`<题号>_中文标题.c/.cpp/.md`；错题保留当时填写的错误答案（重点标注 ❌），并在同处补充正确答案（✅）与错因说明。

## 错题复盘索引

错题在对应文件内保留原始错误答案（❌）并补充正确答案（✅）；下表为索引与错因摘要，可直接点开文件查看完整注释。

### 程序填空 / 选择类（.md）

- [作业1 · 程序填空题](作业1-编程基础/5-1_程序填空题.md)：判断大写字母一题误用 `scanf("%d", &ch)` 按整型读字符，应为 `scanf(" %c", &ch)`；判断条件 `ch >= 'A' && ch <= 'Z'`。
- [作业2 · 程序填空题](作业2-程序控制结构/5-1_程序填空题.md)：
  - 打印菱形下半行前导空格误写 `j <= n - 1`，应为 `j <= n - i`（随行号 i 递减，与上半行对称）。
  - 一元二次方程：判别式应为 `delta = b*b - 4*a*c`；两根为 `(-b + sqrt(delta))/(2*a)`、`(-b - sqrt(delta))/(2*a)`。
- [作业（预）· 程序填空题](作业（预）/5-1_程序填空题.md)：
  - 闰年表达式：`(year%4==0 && year%100!=0) || year%400==0`。
  - 12 小时制时针点数：`(8+t-1)%12+1`。

### 改错类（.cpp）

- [测试1 · 7-2 实验1-1改错（三数平均）](测试1/7-2_实验1-1改错.c)：先累加 `sum = a + b + c;`；赋值用单等号 `average = sum/3;`（原误写判断相等的 `==`）；`average` 为 float，格式符应为 `%.1f`（原误用整型 `%4d`）。
- [作业（预）· 7-2 整数与浮点除法](作业（预）/7-2_改错题整数与浮点除法.c)：`7/2` 是整数除法得 3；浮点除法需先把操作数转为 `(float)a/b`；输出保留 2 位小数用 `%.2f`。
- [作业（预）· 7-3 强制类型转换](作业（预）/7-3_修改程序强制转换.c)：float 参与整型计算会被截断；`c = a + (float)b`，b 截断取整后输出保留 3 位小数 `%.3f`。
- [作业（预）· 7-11 温度转化](作业（预）/7-11_程序改错温度转化.c)：去掉头文件 / 主函数后的多余分号；`scanf` 参数要取地址 `&f`；`5/9` 是整数除法得 0，应写 `5.0/9`；温度用 float，输出 `%.2f`。
- [作业（预）· 7-12 求第三边长度](作业（预）/7-12_程序改错求第三边长度.c)：C 中平方用 `a*a`，不能用 `^`；夹角为角度需先转弧度 `rad = t*π/180`；边长用 double，`scanf` 取地址，输出 `%.2f`。
- [作业（预）· 7-15 三数平均改错](作业（预）/7-15_实验1-1改错求三数平均.c)：先累加 `sum = a + b + c;`；赋值用单等号（原误 `==`）；`average` 为 float，格式符 `%.1f`（原误用 `%4d`）。
- [作业（预）· 7-16 求和与乘积改错](作业（预）/7-16_实验2-1改错求和乘积.c)：三个数均为 float，`scanf` 用 `%f` 且参数取地址；`ac` 应为 `a*c`；乘积输出 `a*c*b`，去掉多余取地址符；输出 `%.6f`。
- [作业（预）· 7-17 输出变量值改错](作业（预）/7-17_实验1-1程序改错输出变量值.c)：2.5 是小数，变量应为 float，且 x、y、z 分别定义；连赋初值 `x = y = z = 2.5;`；输出格式符 `%.2f`。
