## R2-1

写出下面程序的输出结果（  ）。

```c
main()
{
    int x=40, y=4, z=4;
    x = y == z;
    printf("%d  ", x);
    x = x == (y-z);
    printf("%d", x);
}
```

- A、1   0
- B、4   0
- C、1   1
- D、4   1

【参考答案】A（1 0）✓ 作答正确

**解析：** 关系运算优先于赋值。`x = y == z` 中 `y==z`（4==4）为真，x=1；
`x = x == (y-z)` 中 `y-z=0`，`1==0` 为假，x=0。

## R2-2 ⚠️ 错题

下列是合法的 C 语言标识符的是（  ）。

- A、`17`
- B、`auto`
- C、`define`
- D、`6a`

- ❌ **当时作答**：B（auto）——错误
- ✅ **正确答案**：C（`define`）

**解析：** 合法标识符由字母或下划线开头，后跟字母/下划线/数字，且不能是关键字。
- A `17` 是数字常量，不是标识符；
- B `auto` 是 C 关键字，不能作标识符；
- D `6a` 以数字开头，非法；
- C `define` 由字母组成、不是关键字，合法。

## R2-6 ⚠️ 错题

下列程序的执行结果是（  ）。

```c
#define sum 10+20
main()
{
    int b=0, c=0;
    b=5;
    c=sum*b;
    printf("%d", c);
}
```

- A、150
- B、100
- C、110
- D、70

- ❌ **当时作答**：A（150）——错误
- ✅ **正确答案**：C（110）

**解析：** 宏只是直接文本替换，不会自动加括号。`c=sum*b` 展开为
`c=10+20*5=10+100=110`（先乘后加）；若想得到 `(10+20)*5=150`，宏定义应写成 `#define sum (10+20)`。

## R2-7

阅读下面的程序，并判断该程序运行结果是（  ）。

```c
#include "stdio.h"
void main(){
    float x=2.5;
    int y;
    y=(int)x;
    printf("x=%f,y=%d",x,y);
}
```

- A、x=2,y=2
- B、x=2.5,y=2
- C、x=2.500000,y=2.000000
- D、x=2.500000,y=2

【参考答案】D ✓ 作答正确

**解析：** `(int)x` 只把截断后的值赋给 y，x 本身仍是 2.5；`%f` 默认输出 6 位小数 `2.500000`，y 是 int 输出 `2`。

## R2-8 ⚠️ 错题

写出下面程序在 Dev C++ 中的输出结果（  ）。

```c
main()
{
    int I, j;
    I=16;
    j=(I++)+I;
    printf("%d  ", j);
    I=15;
    printf("%d  %d", ++I, I);
}
```

- A、34 16 15
- B、34 16 16
- C、33 16 16
- D、32 16 15

- ❌ **当时作答**：D（32 16 15）——错误
- ✅ **正确答案**：C（33 16 16）

**解析：**
- `I=16; j=(I++)+I;`：后置 `I++` 先用后增，取值 16，I 变为 17，再加当前的 I=17，故 `j=33`。
- `I=15; printf("%d %d", ++I, I);`：`++I` 先增，I 变为 16，两个参数取值都是 16，输出 `16 16`。
- 整体输出 `33 16 16`。

## R2-10 ⚠️ 错题

语句 `scanf("x = %f, y = %f", &x, &y);`，正确的输入是（  ）。

- A、`1.5,2.5`
- B、`1.5 2.5`
- C、`x = 1.5 y = 2.5`
- D、`x = 1.5, y = 2.5`

- ❌ **当时作答**：A ——错误
- ✅ **正确答案**：D

**解析：** scanf 格式串中的普通字符必须在输入中**原样匹配**。格式串里有 `x = `、`, y = `，
所以输入必须带这些字面字符，即 `x = 1.5, y = 2.5`；A、B 缺少 `x = `、`y = ` 字面字符，C 缺少中间的逗号。

## R2-12

`10+'a'+1.5-567.345/'b'` 的结果是（  ）。

- A、long
- B、unsigned float
- C、int
- D、double

【参考答案】D ✓ 作答正确

**解析：** 表达式中含 `1.5`、`567.345` 浮点常量，运算过程中整型/字符型会提升为 double，最终结果为 double 类型。
